# Workflow

The end-to-end process this toolkit operationalises (per the owner's
creative brief).

## 1. Reference deconstruction

Pick the reference. Probe it, extract labeled frames, build contact sheets,
view ALL of them, run onset detection, write the study (techniques + frame
numbers + numbers worth stealing). Skill: reference-deconstruction.

## 2. Plan

Choose an arc (showcase / showreel / kinetic / ad), set the cut budget from
audio density, storyboard one line per beat. Skill: edit-planning.

## 3. Source

Pinterest for look references (study only). Licensed music/SFX/fonts with a
ledger row each. Skill: asset-sourcing.

## 4. Build

Compose the edit in code: captions word-by-word, kinetic type with measured
entrances, overlays and wrappers, palette discipline, events snapped to
onsets. Skills: captions, kinetic-typography, motion-graphics,
colour-theory, audio-sync.

## 5. Render

Deterministic render from the frame clock. Export via tools/encode.sh.
Skill: deterministic-render.

## 6. Verify and deliver

QA sheets viewed, side-by-side technique comparison vs the study, fix loop
one class at a time, honest delivery note. Skill: qa-and-delivery.

## Self-healing loop

Render -> compare -> fix -> re-render until the comparison passes or the
remaining gap is declared in the delivery note. Never declare "matches the
reference" - declare which techniques were reproduced and verified.
