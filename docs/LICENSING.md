# Licensing

## Analysis vs redistribution

This toolkit studies reference videos made by other creators. That study is
analysis: frame extraction, viewing, measurement, written technique notes.
Analysis output (words, numbers, contact-sheet observations kept locally)
is fine.

Redistribution is not: reference frames, frame crops, audio, or video from
reference reels must never be committed to this repo, included in a
deliverable, or posted. Attribution in analysis docs is creator handle +
reel URL.

## Recreation claims

Never claim an output "recreates" or "matches" a reference. Claim the
specific techniques reproduced, with the verification done. Example: "A/B
cut period of 15 frames and 2-4 frame flash transitions reproduced;
verified on rendered frames 90-180."

## Shippable assets

Music, SFX, fonts and stock used in an output need a licence that permits
the use and a row in the project asset ledger (skills/asset-sourcing).
When in doubt, do not ship it.
