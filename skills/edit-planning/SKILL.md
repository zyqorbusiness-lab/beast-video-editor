# Edit planning

## Beat sheets that work (from the reference studies)

**Showcase arc** (edworld, 23s): hook/brand world (2-3s) -> raw state ->
edited state -> breakdown moments -> CTA/end card (2-3s hold).

**Showreel arc** (yunsan, 18s): branded wrapper intro -> 3-5 client
segments (2-4s each, flash/wipe between) -> REACH US end card (3s+ hold).

**Kinetic arc** (metros, 11s): cold open on type -> A/B alternation body
(~0.5s period) -> flash transition -> resolve -> end card.

**Ad arc** (adito, 27s): problem stated in type -> product world -> UI
proof moment -> benefit lines word-by-word -> logo hold.

## Cut budget

Decide cuts-per-10s up front from the audio density (see audio-sync).
Write it in the plan. If the rough cut misses the budget by >30%, re-plan,
don't just trim.

## Storyboard minimum

One line per beat: time range, visual, text on screen, audio event,
transition out. Six beats is a full reel plan. Anything you cannot
storyboard in one line is two beats.

## Gapless timeline rule (from the owner's brief)

Every asset on the timeline has an explicit in/out in frames; no implicit
gaps, no "the editor will figure it out". The render is deterministic from
the plan (see deterministic-render).
